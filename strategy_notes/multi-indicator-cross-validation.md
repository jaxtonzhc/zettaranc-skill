# 多维技术指标交叉验证实战手册（外部收录）

> 来源：他人推荐的策略框架，2026-08-19 收录。
> 定位：人工盯盘时的对照清单（非自动化公式）。
> 状态：**部分观点已经过本地回测验证**，见文末「回测验证记录」。

---

## 核心逻辑总纲

1. 趋势优先：RSI(12)在50上方，才是多头根据地；ADX大于25，趋势才有力度。
2. 提前预警：ADX拐头向下 = 趋势力度减弱，这是领先于MACD死叉的"撤退号"。
3. 共振才出手：MACD、KDJ、布林、RSI、DMI中，至少4个指标同时发出多头信号，才值得扣动扳机。

## 一、大胆加仓买入（重仓/右侧加仓 20%~30%）

场景：趋势已经形成，进入加速主升浪。

| 指标 | 具体条件 |
|---|---|
| MACD | DIF与DEA在零轴上方，红柱持续变长（动能加强） |
| KDJ | 金叉状态，J值在50~80之间（若在100钝化但ADX强势可接受） |
| RSI(12) | > 50 且方向明显翘头向上 |
| 布林带 | 股价放量突破并站上中轨，或沿上轨攀升（开口张大） |
| DMI (ADX) | ADX > 25 且 ADX上穿ADXR（趋势加速），+DI在-DI上方 |
| 成交量 | 明显放量（量比 > 1.5），或持续温和堆量 |

## 二、考虑买入试仓（轻仓 10%）

场景：下跌趋势结束，多空平衡刚刚被打破，属于"左侧试错"或"回踩确认"。

| 指标 | 具体条件 |
|---|---|
| MACD | 在零轴附近金叉，或绿柱持续缩短即将翻红 |
| KDJ | 在50以下金叉并拐头向上（低位金叉） |
| RSI(12) | 从低位（<30）向上突破 40，或回踩中轨时在50止跌翘头 |
| 布林带 | 股价回踩中轨不破，或从下轨反弹刚触及中轨 |
| DMI (ADX) | +DI上穿-DI（金叉），且 ADX > 20 并走平或微翘（不能向下） |
| 成交量 | 温和放量，或回调时极度缩量（地量十字星） |

## 三、减仓/风险警示（只卖不买）

场景：趋势力度衰竭，虽然没有死叉，但风险急剧上升。

| 指标 | 具体条件 |
|---|---|
| MACD | 股价创新高，但红柱连续3根变短（顶背离前兆） |
| KDJ | J值 > 100 高位钝化，或从高位死叉向下 |
| RSI(12) | > 70（超买）且拐头向下，或与股价形成顶背离 |
| 布林带 | 股价紧贴/触碰上轨，但开口走平（非开口张大）且缩量 |
| DMI (ADX) | ADX > 40 后拐头向下，或 ADX 死叉 ADXR（力度双死叉） |
| 成交量 | 缩量上涨（量价背离），或高位放量滞涨 |

## 四、必须立刻卖出清仓（无条件离场）

场景：多头彻底投降，趋势完全破位。

| 指标 | 具体条件 |
|---|---|
| MACD | DIF与DEA在零轴下方形成死叉，或红柱转绿柱 |
| KDJ | 死叉且向下发散，J值在50以下 |
| RSI(12) | < 40 且继续向下，或在50处拐头向下被压制 |
| 布林带 | 跌破中轨且中轨拐头向下，股价沿下轨下滑 |
| DMI (ADX) | ADX虽高但-DI在+DI上方；或ADX在20以下钝化但股价破位 |
| 成交量 | 放量大跌（恐慌盘涌出） |

## 执行口诀

> ADX向下拐，仓位砍一半；RSI破50，清仓不犹豫。

## 回测验证记录（本地数据库，科技/半导体/有色 80+ 只股，2022-2026）

### 已验证 ❌ "共振才出手"（至少4个指标同向）

- 家电板块实测：放量+BOLL中轨+RSI>50 全满足的双金叉，胜率41.0%，
  与裸信号 41.3% **零差异**。MACD/KDJ/RSI/BOLL 都是价格的投影，
  同源性太强，"共振"不等于独立证据。
- 结论：共振清单只能排除最差的信号（三条件全无的信号确实更差），
  不能识别最好的信号。

### 已验证 ⚠️ KDJ J值区间

- 手册买入区 J 50~80：本地数据里 J>60 的金叉是震荡期最差的一档
  （盈亏比1.28），反而是 J≤15 的低位金叉胜率 64-68%。
- 手册的 J 区间假设与 A 股成长板块实测方向相反。

### 已验证 ❌ "ADX 领先撤退"（ADX>40拐头砍一半）

2026-08-19 实测（同一买点、只改卖出规则，DMI(14,6)）：

| 卖出规则 | 熊市期均收益 | 牛市期均收益 | 总收益(熊/牛) |
|---|---|---|---|
| 同日双死叉（基准） | +1.92% | +4.14% | 4084 / 5122 |
| ADX>40拐头全卖 | +1.32% | +2.86% | 3133 / 3994 |
| ADX>25拐头全卖 | +0.32% | +1.70% | 957 / 2969 |
| ADX死叉ADXR | +0.38% | +1.77% | 1143 / 3083 |

结论：ADX 拐头确实比双死叉更早（持有天数 20.8→16.9），但"早"不等于"对"——
被提前踢出的交易里有大量后来收复的，省下的亏损抵不过砍掉的大涨。
该手册的"绝杀逻辑"在本股票池上不成立。
