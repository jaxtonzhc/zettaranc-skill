# 过拟合反推通用策略 Skill

> 通用方法论：给定任意股票/ETF，先用未来函数过拟合找理论最优买卖点，再从极值点反推规律与指标，提炼成 T+1 可执行的通用策略并严格回测验证。本 skill 是流程框架，不绑定任何具体结论。

## 何时使用
- 用户给出一只/一池 股票或 ETF，想找出能跑赢持有的波段策略
- 用户问"这个票怎么买卖最赚"、"有什么指标能抓它的主升浪"
- 用户想验证某个技术策略、或想从"理论最优"反推"实际可执行规则"
- 任何需要"先知道天花板在哪，再谈怎么接近它"的量化探索场景

## 铁律（任何回测必须遵守）
1. T+1 成交：T 日收盘出信号，T+1 开盘成交。禁止当日信号当日成交，那是未来函数
2. 手续费：双边万三（0.0003/边），单笔不足 5 元按 5 元（A股规则，个股适用）
3. 未来函数只用于"找理论上限"，绝不进入最终策略
4. 样本外验证：随机起点滚动入场 + 留出未参与训练的时段验证，防过拟合自嗨

## 流程：反向思维五步法

### 第一步：锁定标的与数据
- 确认标的是 ETF 还是个股、复权口径（必须统一，前后复权差值巨大会误导价位）
- 数据来源统一走 SQLite（data/stock_data.db 的 daily_kline），指数另存
- 加载工具：indicators 模块提供 macd/ kdj / dmi / boll / vol_ratio / crosses 等

### 第二步：过拟合找理论上限（知道未来）
- 方法：峰谷检测，找局部极小值次日买、局部极大值次日卖，涨超阈值(如5%)才成段
- 目的：回答"这标的最多能赚多少"，给后续策略一个参照系，不是用来抄
- 可进一步用区间 DP 求 K 笔交易的最优分段（LeetCode 309 变体），看 K=3/5/8 的天花板
- 记录：每段买卖点的日期、价格、对应涨幅

### 第三步：反推极值点规律（最关键的一步）
- 把第二步的买卖点，回看当时的指标状态，统计占比
- 重点看：MACD/KDJ 金叉死叉占比、价格相对 MA20/MA60 的位置、DMI(PDI/MDI) 动能、量比、J 值
- 常见反直觉结论：最优买点往往不在金叉（金叉已涨一段），而在短期超卖+长期趋势未坏；最优卖点往往在动能极致但未死叉
- 这一步会推翻"顺动能"的直觉，是提炼好策略的核心

### 第四步：提炼通用策略规则
从第三步的统计特征，反推可执行的买卖条件，例如：
- 买入：短期超卖(破MA20/ J<0) + 长期趋势未坏(MA60向上) + 过滤(量比>1.2 或 DIF上拐)
- 卖出：动能极致(PDI高位钝化) 或 放量长上影 或 破MA20且MACD柱转负 —— 不要求死叉
- 空仓：趋势转空(MA20下穿MA60) 彻底空仓，不抄下跌趋势票
- 规则要可量化、可回测，避免模糊词（"差不多"、"明显"）

### 第五步：T+1 严格回测验证
- 用第四步规则实跑，对照"买入持有"基准，看收益/回撤/夏普/胜率
- 若跑输持有或不稳定：回到第三步补充特征（如加趋势过滤、过滤单边下跌票）
- 滚动入场测试：随机起点开始，确认非低点起步也有效
- 达标后再固化成预设或过滤器，接入回测框架

## 复用代码模板（Python，依赖 etf_bt.indicators）
```python
from etf_bt import indicators as ind
def peaks(cl, win=8):  # 峰谷检测
    pts=[]
    for i in range(win, len(cl)-win):
        seg=cl[i-win:i+win+1]
        if cl[i]<=min(seg) and cl[i]<=cl[i-win]: pts.append((i,'L'))
        elif cl[i]>=max(seg) and cl[i]>=cl[i+win]: pts.append((i,'H'))
    return pts
def backtest_ideal(closes):  # 过拟合理论上限
    pts=peaks(closes,8); cash=1.0; pos=None
    for idx,t in pts:
        if t=='L' and pos is None: pos=idx
        elif t=='H' and pos is not None:
            if closes[idx]>closes[pos]*1.05: cash*=closes[idx]/closes[pos]
            pos=None
    return cash-1
```

## 交付物
- 该标的的"理论收益天花板"（过拟合上限）
- 极值点指标特征统计表
- 一套 T+1 回测过的通用买卖规则
- 与"买入持有"的对比结论（是否值得做）

## 已知坑（避坑清单）
- 复权口径不统一：前后复权价差巨大，价位判断全错，先确认软件口径
- 数据源断层：拉全历史时分段拉（单次接口限~800条），并检查单日跳变>50%的脏数据
- 过拟合切太碎：段数过多会把噪声当趋势，理论上限反而虚低；用最小涨幅阈值+合理段数约束
- 顺动能陷阱：双金叉/双死叉本质是追涨杀跌，在波动大的票上假信号极多，需叠加趋势过滤
- 防御资产/单边下跌票：动量策略普遍失效，应先排除或加趋势门控
